🎯 Goal Tracker

Goal Tracker is a React Native Expo application that helps users create, manage, and track personal goals. Goal data is managed using React state instead of a database, allowing users to add, update, delete, and monitor their goals through a simple and interactive interface.

✨ Key Features

* 🎯 Create personal goals
* ➕ Add new goals
* ✏️ Update existing goals
* 🗑️ Delete goals
* 👁️ View and monitor goals
* 📊 Track goal progress
* 🔄 React state-based data management
* 🚫 No database dependency
* 📱 Clean and responsive React Native UI
* ⚡ Instant UI updates
* 🎯 Simple goal management workflow
* 🧩 Reusable React components

🏗️ Architecture & Workflow

The application provides an intuitive interface for creating and managing personal goals. Users can add a goal, view their existing goals, update goal information, or remove goals when they are no longer needed.

Goal data is maintained using React state, allowing changes to be reflected immediately in the user interface without requiring a backend or database. The application manages different goal states through a simple component-based workflow.

🛠️ Tech Stack

React Native • Expo • JavaScript • React Hooks • State Management • CRUD Operations • Component-Based UI • Responsive Design

▶️ Run the App

1. Install dependencies

npm install

2. Start Expo

npx expo start

3. Run on Android

npx expo start --android

4. Run on iOS

npx expo start --ios

5. Run on Web

npx expo start --web

🎯 Project Purpose

This project demonstrates how to build a simple goal management application using React Native and Expo without backend or database dependencies. It provides practical experience with React state management, CRUD operations, user input handling, conditional rendering, reusable components, and creating interactive mobile interfaces.
